# Leaves 落葉拼圖（網頁版）

單人疊牌解謎小遊戲的網頁移植版，玩法架構沿用先前《寶可夢排球》專案的做法：單一 `index.html`、PWA 可安裝、支援手機觸控、繁中/簡中/日文/英文四語言切換。

玩法概念取材自桌遊《Leaves 葉漫漫》（Play With Us Design 玩聚設計）。

## Features
- 3×3 格落葉卡疊牌解謎，單人 Zen 模式 / 計時挑戰模式
- 本機排行榜（分數、耗時、使用上一步次數、玩家名稱）
- 新手教學、上一步、重新發牌
- 疊牌手感：飛行動畫、擠壓彈跳、閃白、粒子、畫面震動
- 繁中 / 簡中 / 日文 / 英文
- PWA：可安裝到手機主畫面，離線開啟

## Play
用瀏覽器開啟 `index.html`，或架設靜態伺服器後開啟。
